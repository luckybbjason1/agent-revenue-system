# Agent Revenue System

> 自动化收入管理系统 - 整合所有赚钱项目

[![Python Version](https://img.shields.io/badge/python-3.8+-blue.svg)](https://www.python.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## 🚀 功能

- **📊 项目追踪**: 管理所有收入项目
- **💰 收入统计**: 自动计算月度/累计收入
- **🔧 自动化**: 定时任务和数据更新
- **📈 报告生成**: 详细收入分析报告

## 📦 安装

```bash
git clone https://github.com/user/agent-revenue-system.git
cd agent-revenue-system
pip install -e .
```

## 🎯 快速开始

### 扫描项目

```bash
revenue-system scan
```

### 查看状态

```bash
revenue-system status
```

### 生成报告

```bash
revenue-system report
```

### 设置自动化

```bash
revenue-system automation
```

## 📊 项目类型

| 类型 | 说明 | 收入模式 |
|------|------|----------|
| **open_source** | 开源项目 | GitHub Sponsors |
| **saas** | 软件即服务 | 订阅制 |
| **marketplace** | 技能商店 | 销售分成 |
| **python_package** | Python 包 | 付费版本 |

## 💰 收入策略

### 开源项目
- GitHub Sponsors
- Open Collective
- 付费支持/咨询

### SaaS 产品
- 月订阅 ($10-100/月)
- 年订阅 (8折)
- 企业授权

### 技能商店
- 一次性销售 ($5-50)
- 订阅更新 ($5-20/月)
- 批量授权
